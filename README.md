# FindingCoordinates

依台灣時間查詢未來一小時內開始的城市時區資訊與座標。

## 功能

1. 使用目前台灣時間查詢。
2. 手動輸入日期時間，格式：`YYYYMMDD HH:MM`。
3. 以輸入時間所在的整點作為查詢起點。
4. 查詢起點至下一個整點之間開始的城市。
5. 顯示城市當地時間、城市名稱、Latitude、Longitude。
6. 純前端執行，不需要資料庫、不需要後端。
7. 可直接部署至 GitHub Pages。

## 範例

輸入：

`20260731 15:30`

程式會以 `2026/07/31 15:00` 台灣時間作為查詢起點，因此會列出：

```text
7/31(五) 15:00-16:00 諾美亞 -22.285410, 166.445664
7/31(五) 16:00-17:00 布里斯班 -27.469553, 153.026319
7/31(五) 16:00-17:00 雪梨 -33.873966, 151.206727
7/31(五) 16:30-17:30 阿得雷德 -34.924074, 138.600717
```

## 部署

將 `index.html`、`style.css`、`app.js` 放到 GitHub repository 根目錄後，即可使用 GitHub Pages 發布。

本專案不使用 API、不寫入資料庫。
